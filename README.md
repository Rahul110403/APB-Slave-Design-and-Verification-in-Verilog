# APB-Slave-Design-and-Verification-in-Verilog
This project implements a simple APB (Advanced Peripheral Bus) slave in Verilog based on the ARM AMBA. It demonstrates basic read and write operations along with simulation using a Verilog testbench.  Features APB Slave RTL design in Verilog Supports read and write operations 4 internal registers Address decoding using PADDR[3:2] .
